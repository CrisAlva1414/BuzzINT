CÓMO USAR
================================================================================

1. EJECUTAR TODOS LOS PIPELINES (simple):
   python run_pipeline_tests.py

2. CON DATOS DE EJEMPLO (si no hay datos reales):
   python run_pipeline_tests.py --reset --create-samples --skip-db

3. VER ESTADO DE PIPELINES:
   python run_pipeline_tests.py --status

4. LIMPIAR REGISTROS:
   python run_pipeline_tests.py --clean

5. EJECUTAR VALIDACIÓN TESTS:
   python -m pytest tests/test_pipeline_validation.py -v

6. EJECUTAR TODO (test + validación + reporte):
   python run_pipeline_tests.py --reset --create-samples
